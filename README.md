# מתמטיקה ח׳ — חזרה למבחן 1

A simple Hebrew, right-to-left study site containing the review page and three complete interactive exams copied from https://ron828.top/math-8/exam-1-review/.

The questions, answer keys, diagrams, calculator, automatic scoring, explanations and browser-local progress saving are preserved. The presentation is simplified with a responsive neutral layout and a restrained green accent. No build process or external dependencies.

## GitHub Pages
Publish the `main` branch from `/ (root)`. The organization site is https://hfsmath8b.github.io/.

## Local preview
Serve this folder with any static web server. Progress is stored only in the current browser and origin.
